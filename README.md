# Simple Windows Setup/Debloat Tool

**By PaladinXV**

A simple, open source Windows Setup/Debloat tool that can setup/debloat Windows to your liking. Ideally it should be ran on a fresh Windows install. 

## How to use

Open PowerShell and run:

```powershell
irm https://raw.githubusercontent.com/PaladinXV/Simple-Windows-11-Setup-Debloat-Tool/main/Launch.ps1 | iex
```
